# Default

Default QymCAD icon set designed from scratch, inspired by modern mobile CAD ergonomics.

## Overview
- **ID**: `default`
- **Name**: Default
- **Version**: `1.0.0`
- **Package Type**: `IconTheme`
- **Color Mode**: Adaptive (uses CSS color tokens like `var(--token, fallback)` for live adaptation to UI color schemes)
- **Author**: braindefender
- **License**: AGPL-3.0-or-later
- **Coverage**: 100% (complete coverage of CAD icons)

## Icon Categories
- **Sketch** (32): lines, arcs, circles, rectangles, polygons, slots, ellipses, splines, fillets, chamfers, trims, extends, offsets, dimensions, and transform tools.
- **Constraints** (12): coincident, collinear, concentric, equal, horizontal, vertical, parallel, perpendicular, tangent, symmetric, midpoint, and lock.
- **Part** (34): extrude, revolve, loft, sweep, fillet, chamfer, draft, shell, hole, thread, booleans, split, patterns, mirror, measure, and primitives.
- **Assembly** (10): ground, relations, joints, insert components, new part, subassemblies, groups, arrays, and width/tangent tools.
- **Datum** (4): planes, axes, points, and sketch plane picker.
