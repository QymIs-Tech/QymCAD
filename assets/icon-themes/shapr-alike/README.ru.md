# Shapr-Alike

Иконки QymCAD, вдохновлённые Shapr3D.

## Обзор

- **ID:** `shapr-alike`
- **Название:** Shapr-Alike
- **Версия:** `1.0.0`
- **Тип пакета:** `IconTheme`
- **Цветовой режим:** Адаптивный — использует динамические CSS-токены (`var(--token, fallback)`) для адаптации к активной палитре CAD.
- **Автор:** braindefender
- **Лицензия:** AGPL-3.0-or-later.
- **Покрытие:** 100% (полное покрытие иконок CAD).

## Категории иконок

- **Эскиз** (32): линии, дуги, окружности, прямоугольники, многоугольники, пазы, эллипсы, сплайны, скругления, фаски, обрезка, удлинение, смещение, размеры и инструменты трансформации.
- **Ограничения** (12): совпадение, коллинеарность, концентричность, равенство, горизонтальность, вертикальность, параллельность, перпендикулярность, касание, симметрия, середина и фиксация.
- **Детали** (34): выдавливание, вращение, лофт, протяжка, скругление, фаска, уклон, оболочка, отверстие, резьба, булевы операции, разделение, массивы, зеркало, измерение и примитивы.
- **Сборка** (10): фиксация, связи, соединения, вставка компонентов, новая деталь, подсборки, группы, массивы и инструменты ширины/касания.
- **Базовая геометрия** (4): плоскости, оси, точки и выбор плоскости эскиза.
