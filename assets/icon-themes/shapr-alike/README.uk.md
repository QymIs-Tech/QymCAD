# Shapr-Alike

Іконки QymCAD, натхненні Shapr3D.

## Огляд

- **ID:** `shapr-alike`
- **Назва:** Shapr-Alike
- **Версія:** `1.0.0`
- **Тип пакета:** `IconTheme`
- **Колірний режим:** Адаптивний — використовує динамічні токени CSS (`var(--token, fallback)`) для адаптації до активної палітри CAD.
- **Автор:** braindefender
- **Ліцензія:** AGPL-3.0-or-later.
- **Покриття:** 100% (повне покриття іконок CAD).

## Категорії іконок

- **Ескіз** (32): лінії, дуги, кола, прямокутники, багатокутники, пази, еліпси, сплайни, скруглення, фаски, обрізання, подовження, зміщення, розміри та інструменти трансформації.
- **Обмеження** (12): збіг, колінеарність, концентричність, рівність, горизонтальність, вертикальність, паралельність, перпендикулярність, дотичність, симетрія, середина та фіксація.
- **Деталі** (34): видавлювання, обертання, лофт, протягування, скруглення, фаска, ухил, оболонка, отвір, різьба, булеві операції, розділення, масиви, дзеркало, вимірювання та примітиви.
- **Збірка** (10): фіксація, зв'язки, з'єднання, вставка компонентів, нова деталь, підзбірки, групи, масиви та інструменти ширини/дотичності.
- **Базова геометрія** (4): площини, осі, точки та вибір площини ескізу.
