# Circular array

Select the body, set the count and the axis above, the angle at the geometry, watch the preview,
press Enter.

![Eight copies around a circle: the distance from the axis is set by the part itself.](img/part-array-circular.png)

## What is set

- **Count** of copies around the circle.
- **Axis** — what to rotate about: a coordinate axis, a datum axis, the axis of a cylinder.
- **Angle** — a full circle or a sector.

## Full circle and step

For an even circle set the full 360°: the program spreads the copies around by itself. A sector is
needed when the features do not go all the way round — four holes on a quarter of a flange, say.

## A hint

Take the axis from a datum axis or from an existing cylinder rather than by eye: then the array stays
coaxial with the part through any change.
