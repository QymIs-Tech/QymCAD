# Machining

The machining module (CAM) is an **add-on** enabled separately in the settings. While the checkbox is off,
it is nowhere in the program: no workbench, no settings section, not even this article in the
contents.

## What already works

Toolpaths, material removal simulation and NC output through a postprocessor. That is enough to get
a part to the machine.

## What is missing

The module is **being reworked**, so there is no detailed reference for its tools here yet: it would
describe what is about to change. It will arrive together with the updated module.
