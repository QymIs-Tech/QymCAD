# Обработка

Модуль обработки (CAM) — **дополнение**, которое включают отдельно в настройках. Пока галочка снята, его в
программе нет нигде: ни верстака, ни раздела настроек, ни этой статьи в оглавлении.

## Что уже работает

Траектории, симуляция съёма и вывод управляющей программы постпроцессором. Этого хватает, чтобы
довести деталь до станка.

## Чего пока нет

Модуль **переделывается**, поэтому подробной справки по его инструментам здесь ещё нет: она описывала
бы то, что скоро изменится. Появится вместе с обновлённым модулем.
