# Сообщить о проблеме

**Справка -> Сообщить о проблеме**.

Опишите беду своими словами: что делали, чего ждали, что вышло вместо этого. Программа соберёт файлы
в одну папку и заполнит форму заранее — останется перетащить файлы и отправить.

## Что прикладывается

| галка | что уходит |
|---|---|
| сведения о сборке и машине | версия, система, видеокарта, язык — ничего личного |
| снимок окна | картинка окна целиком, как оно выглядит сейчас |
| последний файл сбоя | запись прошлого падения, если оно было |
| документ проекта | ваш файл `.qcad` целиком |

**Документ по умолчанию не прикладывается.** Сообщение в трекере открыто всем и навсегда: приложите
файл — и модель увидит любой. Галка ваша, и решать вам. Без документа отчёт тоже принимается: часто
хватает снимка и описания.

## Две кнопки

- **Собрать файлы** — складывает всё в папку и показывает путь. Путь копируется кнопкой рядом.
- **Открыть форму** — открывает страницу в браузере с уже заполненным описанием. Файлы перетащите в
  неё из собранной папки: по ссылке они не передаются.

Порядок любой, но удобнее сперва собрать, потом открыть форму — папка уже будет под рукой.

## Если программа закрылась сама

При следующем запуске она об этом скажет и покажет, где лежит запись. Эта запись и есть «последний
файл сбоя» из таблицы выше: включите галку, и он уйдёт вместе с отчётом. Сообщение показывается один
раз, но файл остаётся на месте.

## Что написать, чтобы поняли с первого раза

- **Что делали** — по шагам: что открыли, что выбрали, что нажали.
- **Чего ждали** — одна строка. «Скругление должно было взяться».
- **Что вышло** — тоже одна строка. «Ничего не произошло, деталь осталась прежней».

Строка **Сборка** из окна «О программе» уходит сама, вручную её переписывать не нужно.

## Если кнопки не срабатывают

Кнопки недоступны, пока не заполнено «что случилось». Форма не открылась — проверьте, что в системе
назначен браузер; текст при этом никуда не делся, он лежит в файле `report.md` в собранной папке, и
его можно вставить в форму руками.
