# Сплайн

Клавиша **N**. Гладкая кривая по точкам: кликайте узлы, **двойной клик** заканчивает.

![Сплайн по четырём точкам: гладкая кривая, проходящая через них.](img/sketch-spline.png)

## Осторожно с определённостью

Сплайн — самая свободная сущность эскиза: у каждого его узла две степени свободы, и «определить» его
целиком размерами почти невозможно. Это нормально для художественной формы и плохо для
ответственного контура.

Правило простое: где форму задаёт **функция** (обвод, аэродинамика, эргономика) — сплайн уместен;
где размер (посадка, отверстие, стык) — лучше линии и дуги.

## Совет

Концы сплайна стоит прибить совпадением к соседним сущностям, иначе при первой же правке контур
разойдётся в стыке.
