# Зеркало в эскизе

Клавиша **M**. Выберите сущности, затем ось: ею служит выбранная линия, а если её нет — ось Y.

## Симметрия связью, а не копией

Отражённые сущности связаны с оригиналом **симметрией**. Это значит, что правка одной половины
переносится на вторую сама, и что определять надо только одну половину — вторая получает
определённость даром.

## Как этим пользуются

Для симметричной детали рисуют половину, ставят осевую **вспомогательной** линией (клавиша X) и
отражают. Осевая не попадёт в профиль тела, но останется опорой симметрии.
