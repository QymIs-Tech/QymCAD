# Отверстие

Клавиша **O**. Выберите тело, укажите грань, задайте диаметр и глубину, Enter.

![Сквозное отверстие в верхней грани: команда помнит грань, а не координаты.](img/part-hole.png)

## Почему не вырез окружностью

Отверстие хранит **ссылку на грань**, а не координаты. Поэтому оно едет вместе с гранью: изменили
деталь выше по построению — отверстие осталось там, где задумано, а не там, где случайно оказались
координаты.

Вырез окружностью такой связи не имеет и после правки может уехать.

## Разметка по точкам

Если в эскизе на грани стоят точки, отверстия можно поставить по ним — тогда их положение
параметрично и правится размерами эскиза.

## Глубина

Глухое отверстие задаётся числом, сквозное — глубиной заведомо больше толщины либо соответствующим
режимом. Для резьбы используйте команду **Резьба** по готовому отверстию.
