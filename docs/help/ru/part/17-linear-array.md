# Линейный массив

Выберите тело, задайте сверху количество и направление, шаг — у геометрии, смотрите превью, Enter.

![Массив 3×2: копии расставлены по двум направлениям.](img/part-array-linear.png)

## Массив — одна фича

Все копии живут одним узлом ленты. Поэтому количество и шаг правятся в одном месте, а удаление
массива убирает все копии разом, не оставляя мусора.

## Что задаётся

- **Количество** — сколько всего, включая исходное.
- **Направление** — по какой оси или вдоль какого ребра.
- **Шаг** — расстояние между соседними копиями; принимает формулу.

## Совет

Шаг удобно связать с глобальным параметром: `pitch`. Тогда перестановка отверстий на плате — правка
одного числа, а не пересборка массива.
