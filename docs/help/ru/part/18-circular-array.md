# Круговой массив

Выберите тело, задайте сверху количество и ось, угол — у геометрии, смотрите превью, Enter.

![Восемь копий по кругу: расстояние от оси задаёт сама деталь.](img/part-array-circular.png)

## Что задаётся

- **Количество** копий по кругу.
- **Ось** — вокруг чего вращать: ось координат, датум-ось, ось цилиндра.
- **Угол** — полный круг или сектор.

## Полный круг и шаг

Для равномерного круга задают полные 360°: программа сама разложит копии по кругу. Сектор нужен, когда
элементы идут не по всей окружности — например, четыре отверстия на четверти фланца.

## Совет

Ось лучше брать датум-осью или осью существующего цилиндра, а не «на глаз»: тогда массив останется
соосным детали после любой правки.
